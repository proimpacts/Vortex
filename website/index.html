Make Yapin yours.

Vortex adds plugins, themes and a better Settings to the Yapin desktop app. It starts Yapin for you and never edits its files, so going back to plain Yapin is just opening it normally.

This is the real launcher, running in your browser. Click a choice or use the arrow keys and Enter.

      

    


    

      
Everything is a switch.

      
Nothing changes until you turn it on, and everything can be turned off again.

      

        

          
Plugins, one switch each

          
Better search, quick chat, a message logger, unread jumps, nicer sliders. Take what you want and leave the rest. Try the switches.

Themes are just CSS

          
One file changes the whole look. Dark, glass, terminal, blueprint: yours can be a few lines.


:root {
  --accent: #b69cff;
  --bg-main: #0b0a12;
}

        

        

          
Make and share your own

          
A plugin is one .js file. Write it in the app, preview it live, and export it to share.


definePlugin({
  name: 'HelloWorld',
  start(api) { api.log('hi'); },
});

        

        

          
Your data stays yours

          
Settings and message history are kept in a file on your computer. Login and session data are never saved.

        

        

          
Updates look after themselves

          
Vortex checks for new versions when it starts and installs them safely, with a backup it can restore.

        

      

    


    

      
How it works

      
    
        
  1. 1
    You open Vortex
    It finds your Yapin install, closes Yapin if it is open, and starts it.
    2. 
        
  2. 2
    Vortex joins the page
    Its plugins and themes load before the first screen is drawn, so nothing flashes in late.
    3. 
        
  3. 3
    You change what you like
    Open Settings, scroll to Vortex, and switch things on. Close it and Yapin is plain again.
    4. 
      

      

        
Built to be removed
Yapin's files are never edited. Uninstall from the launcher, or just open Yapin the normal way.

        
You stay in charge
Plugins can read and change everything in Yapin, including messages. Only run ones you wrote or trust.

        
Updates are checked
Downloads come from GitHub over HTTPS, are checked and backed up first, and roll back if anything fails.

Questions

      
Is it finished?
No. Vortex is in alpha: it works and is used daily, but it is young, so expect some rough edges. Tell us what breaks.

      
Is this safe?
Vortex never edits Yapin's files, and updates only come from the project's GitHub page over HTTPS, checked and backed up first. Plugins are powerful, so only run ones you trust.

      
Will it get me banned?
Vortex only changes how the app looks and works on your own computer. It is not made by the people behind Yapin, so check their Terms of Service before you use any mod.

      
How do I go back to plain Yapin?
Quit Yapin from the tray icon and open it the normal way. You can uninstall Vortex from its launcher.

      
Does it work on Mac?
Not yet. Yapin has no Mac app, and Vortex needs the desktop app.

      
Where do I get Vortex?
Only from this site or the GitHub page. Anything else claiming to be Vortex is not.

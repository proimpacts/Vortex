What's inside

      

        

          

            
Plugins, one switch each

            
Better search, a quick switcher, a message logger, a saved-messages inbox, a music player, focus tools and more. 61 optional plugins, each with its own settings, and 7 required ones that make Vortex work. Everything is off until you turn it on. Try the switches.

Themes

          
25 looks, from a calm dark to a green terminal, a blueprint, a synthwave sunset and a retro grey desktop. A theme is one file of CSS.

        

        

          
A Settings that fits

          
One full-screen page with Vortex's own sections inside it, and plugin pop-ups that follow your theme.

        

        

          
Make your own

          
A plugin is one .js file. Write it in the app, preview it live, and export it to share.

        

        

          
Your data stays yours

          
Settings and message history live in a file on your computer. Login and session data are never saved.

        

        

          
Updates that look after themselves

          
New versions are checked, backed up first, and rolled back if anything goes wrong.

How it works

      
    
        
  1. 1
    You open Vortex
    It finds your Yapin install, closes Yapin if it is open, and starts it.
    2. 
        
  2. 2
    Vortex joins the page
    Plugins and themes load before the first screen is drawn, so nothing flashes in late.
    3. 
        
  3. 3
    You change what you like
    Open Settings, scroll to Vortex and switch things on. Close it and Yapin is plain again.
    4. 
      

      

        
Built to be removed. Yapin's files are never edited. Uninstall from the launcher, or just open Yapin the normal way.

        
You stay in charge. Plugins can read and change everything in Yapin, including messages. Only run ones you wrote or trust.

        
Updates are checked. Downloads come from GitHub over HTTPS, are backed up first, and roll back if anything fails.

Questions

      

        
Is it finished?
No. Vortex is in alpha: it works and is used daily, but it is young, so expect some rough edges. Tell us what breaks.

        
Is this safe?
Vortex never edits Yapin's files, and updates only come from the project's GitHub page over HTTPS, checked and backed up first. Plugins are powerful, so only run ones you trust.

        
Will it get me banned?
Vortex only changes how the app looks and works on your own computer. It is not made by the people behind Yapin, so check their Terms of Service before you use any mod.

        
How do I go back to plain Yapin?
Quit Yapin from the tray icon and open it the normal way. You can uninstall Vortex from its launcher, and "Uninstall and Delete All Data" removes every trace of it.

        
Does it work on Mac?
Not yet. Yapin has no Mac app, and Vortex needs the desktop app.

        
Where do I get Vortex?
Only from this site or the GitHub page. Anything else claiming to be Vortex is not.

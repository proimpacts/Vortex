# Changelog

## 0.3.2 (alpha)
- UI Enhancements: your account card now runs under the server list, like Discord, and the voice call panel and music player line up with it.
- Uninstall and Uninstall and Delete All Data now really delete, check that the folders are gone, and say so if something could not be removed.

## 0.3.1 (alpha)
- New launcher choice: **Uninstall and Delete All Data**. It removes Vortex and every trace of its data for the current user: settings, plugin data, your own plugins and themes, saved messages, the backup and the logs, including Vortex's copy inside Yapin's own storage. Plain **Uninstall** now keeps your settings.
- Added the Apache License 2.0 and a NOTICE file.
- Website and README wording about Linux made plainer.

## 0.3.0 (alpha)
- New plugins: QuickSwitcher (Ctrl+K), FontPicker, UIScale, AlwaysOnTop, CopyCodeButton, BigEmoji, FocusTimer and SpellcheckToggle.
- Every theme now says who made it, with a picture and a link, the same as plugins. Clicking the name opens a page with that person's plugins and themes.
- Alpha release: README, website and release notes say so, with a list of known limits.

## 0.2.3
- Light themes: readable text boxes and light native controls in Settings.

## 0.2.2
- Plugin pop-ups and the music player take on the look of the active theme.

## 0.2.1
- Better Folders simplified: it only gives Yapin's folders the Discord folder icon and sizing.

## 0.2.0
- Six more full-redesign themes (Amber CRT, Matrix, Retro 98, Brutalist, Blueprint, Synthwave), 25 in all.
- A website with a theme gallery. Terminal launcher with Install, Repair and Uninstall that closes Yapin for you.

## 0.1.0
- First version: plugins, themes, a redesigned Settings, backups, add-ons and auto-update.
